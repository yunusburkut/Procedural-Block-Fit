Unity Editor Tool — User Guide

▦ Blokfit Level Editor

A custom Unity EditorWindow for hand-authoring puzzle levels by painting triangles on a visual grid and exporting them as JSON for the runtime loader.

Tools ▸ Blokfit ▸ Level Editor Ctrl + Alt + L Blokfit.LevelEditor Editor-only assembly

1 — Opening the Editor

The Level Editor is accessible from two places:

  • Unity menu bar: Tools ▸ Blokfit ▸ Level Editor
  • Keyboard shortcut: Ctrl + Alt + L

The window opens as a dockable Unity panel (minimum size 760 × 540 px). Its state — grid size, piece list, and all triangle assignments — survives domain reloads and Unity restarts because all fields are marked [SerializeField].

The window has three sections:

  • Left panel (240 px) — Grid Settings slider and the scrollable Pieces list.
  • Right panel (fills remaining space) — interactive triangle grid on a dark background.

3 — Step-by-Step Workflow

Set the grid size

Use the Size (N) slider (range 2–10) to choose the board dimensions. An N×N board contains N² square cells, each split diagonally into two right-angle triangles — so a 4×4 grid yields 32 triangles total.

Moving the slider reveals an Apply button (shown in amber). Clicking Apply clears all triangle assignments but keeps the piece list intact. A confirmation dialog prevents accidental resets.

Tip Use 4×4 for easy levels (32 triangles), 6×6 for medium (72), and 8×8 for hard (128).

Create pieces

Click ＋ New Piece to add an entry to the Pieces list. Each piece row contains:

  • Colour square — click to open Unity's colour picker. New pieces are automatically assigned a distinct hue from a 10-colour palette.
  • Name field — editable label (e.g., "Piece 0"). Purely for author convenience; not stored in the JSON output.
  • Triangle counter — updates live as you paint.
  • Select / ✔ indicator — click "Select" or anywhere on the row to make the piece active. The active row is highlighted in blue and shows a green ✔.
  • ✕ delete button — removes the piece and unassigns all triangles it owned. Piece indices of subsequent pieces are decremented automatically.

Paint triangles

With a piece selected, click triangles inside the dark grid panel on the right. The grid uses the same triangular half-cell system as the runtime: each square cell is divided by a / diagonal into two triangles.

Lower triangle
Bottom-right half
type = 0  ·  vertices: BL, BR, TR
Upper triangle
Top-left half
type = 1  ·  vertices: BL, TR, TL

Mouse interactions:

  • Left-click — assigns the clicked triangle to the currently selected piece. If the triangle already belongs to that piece, it is unassigned (toggle behaviour).
  • Right-click — always unassigns the triangle, regardless of which piece owns it.

The active piece's triangles appear slightly brighter than the rest so you can see your work at a glance. Unassigned triangles are rendered in a neutral dark grey.

Note The grid's coordinate system keeps row 0 at the bottom (matching Unity's world-space Y-up convention). The screen Y axis is inverted, so row 0 appears at the bottom of the grid panel.

Export JSON

When the level is ready, click ⬇ Export JSON in the toolbar.

  1. If any triangles are unassigned, a warning dialog appears. You can choose to continue or cancel and fix the gaps.
  2. A Save File panel opens, defaulting to Assets/Resources/Levels/ (created automatically if it doesn't exist). Choose any name with a .json extension.
  3. The file is written and, if the path is inside Assets/, AssetDatabase.ImportAsset is called automatically — the file appears in the Project browser without a manual refresh.
Recommended save path Assets/Resources/Levels/level_handmade_01.json
Tip Pieces with zero assigned triangles are silently skipped during export — you don't need to delete empty pieces before exporting.

4 — JSON Output Format

The exported file serialises a LevelData object using JsonUtility.ToJson(..., prettyPrint: true). The schema is:

FieldTypeDescription
grid.size int Board side length N. Board has N×N cells and 2N² triangles.
pieces[i].cells int[] Triangle flat-indices belonging to this piece. Formula: (row × N + col) × 2 + type
pieces[i].color string HTML hex colour, e.g. "#4A90D9". Derived from the colour picker value.
pieces[i].anchors int[] Single-element array containing the smallest flat-index in cells (bottom-left-most triangle). Used as the piece's pivot vertex at runtime.
pieces[i].spawnX float Always 0 when exported from the editor. Scattered at runtime by GameManager.ScatterSpawnPositions().
pieces[i].spawnY float Always 0 when exported from the editor. See above.

Example output for a 4×4 board with two pieces:

{
    "grid": {
        "size": 4
    },
    "pieces": [
        {
            "cells": [ 0, 1, 2, 8, 9 ],   // triangle flat-indices
            "color": "#4A90D9",             // from colour picker
            "anchors": [ 0 ],              // smallest flat-index
            "spawnX": 0.0,
            "spawnY": 0.0
        },
        {
            "cells": [ 3, 4, 5, 6, 7 ],
            "color": "#D94A70",
            "anchors": [ 3 ],
            "spawnX": 0.0,
            "spawnY": 0.0
        }
    ]
}

Flat index formula

Every triangle is identified by a single integer derived from its position: 

flat = (row × N + col) × 2 + type

// Example for a 4×4 grid (N = 4):
// Cell (col=1, row=0), lower triangle (type=0):
flat = (0 × 4 + 1) × 2 + 0 = 2

// Cell (col=1, row=0), upper triangle (type=1):
flat = (0 × 4 + 1) × 2 + 1 = 3

5 — Loading the Level at Runtime

  1. Save the JSON file inside Assets/ (recommended: Assets/Resources/Levels/).
  2. In the Unity Scene, select the GameManager GameObject.
  3. In the Inspector, expand the Handmade Levels list and drag the JSON TextAsset into a slot.
  4. Press Play and click the Handmade button in the game UI.
Runtime behaviour Multiple JSON files can be added to the list. They are cycled in order each time the Handmade button is pressed. Spawn positions (always 0 in exported files) are automatically distributed around the tray by ScatterSpawnPositions(), which places pieces in a circular arc with a small random jitter.

6 — How the Editor Works Internally

State persistence

The window's fields are decorated with [SerializeField], which means Unity serialises them into the window's internal state. This keeps the grid and piece list intact across domain reloads (script compilation) and Editor restarts.

Triangle assignment array

A flat int[] called _owner of length N × N × 2 tracks which piece owns each triangle. The value is -1 for unassigned and ≥ 0 for a piece index. This array is the single source of truth for both rendering and export.

Grid rendering

The grid panel is drawn using Handles.DrawAAConvexPolygon (anti-aliased fill) and Handles.DrawAAPolyLine (outline) inside a Handles.BeginGUI / EndGUI block. Each frame only the triangles that changed need to be redrawn; Repaint() is called explicitly on mouse events rather than every frame.

Hit-testing

Clicking the grid panel runs a point-in-triangle test (sign / cross-product method) for every triangle in the grid to determine which one was clicked. Because the number of triangles is at most 200 (10×10 grid), this brute-force scan is imperceptible. 

// Determines the sign of the cross-product to check which side of each edge the point is on.
static float Cross(Vector2 pt, Vector3 u, Vector3 v)
    => (u.x - pt.x) * (v.y - pt.y) - (u.y - pt.y) * (v.x - pt.x);

// Point is inside iff all three cross-products have the same sign.
bool hasNeg = d1 < 0 || d2 < 0 || d3 < 0;
bool hasPos = d1 > 0 || d2 > 0 || d3 > 0;
return !(hasNeg && hasPos);

Export pipeline

Export iterates over the piece list, collects the flat indices owned by each piece into a List<int>, picks the minimum index as the anchor, converts the colour to an HTML hex string via ColorUtility.ToHtmlStringRGB, and builds a PieceJson per piece. The root LevelData is finally serialised by the shared LevelSerializer.ToJson() utility.
